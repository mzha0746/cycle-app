# How to use?

* Install visual studio code
* Install uv here: https://docs.astral.sh/uv/getting-started/installation/
* On the root directory, run `uv sync` and wait for the .venv to be created
* Activate the venv in visual studio code
* Run each app.py under the apps folder

# How to build as exe?

* cd ./apps
* run pyinstaller app.py
